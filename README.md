# AntiGravity 懶人包技能庫 (antigravity-lazy-packs)

本儲存庫收錄專為 Google AntiGravity AI Agent 設計的實用技能（Skills）與環境配置懶人包。

## 📦 技能清單

| 檔名 | 技能說明 | 觸發關鍵字 |
| :--- | :--- | :--- |
| **[01-連接-clasp.md](./01-連接-clasp.md)** | Google Apps Script (clasp) 環境自動檢測、跨平台安裝 (Windows/macOS/iOS) 與專案建置指引 | 「連接 clasp」、「設定 clasp」、「開發 GAS」、「GAS 環境」 |

---

## 🚀 使用方式

將對應的 `.md` 檔案複製至 AntiGravity 的自訂技能目錄：
- 全域路徑：`~/.gemini/config/skills/<技能目錄>/SKILL.md`
- 專案路徑：`<專案目錄>/.agents/skills/<技能目錄>/SKILL.md`
